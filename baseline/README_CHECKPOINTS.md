# Baseline quick-run checkpoints (`baseline/`)

GraphGdel-compatible `.sav` files for the `quickrun/quick_run_baseline_*.py` scripts (DNN, DeepGDel, NMA, GraphGDel).

Shipped **in this GitHub repository** for *e_coli_core* quick-start comparisons.

## Required (`e_coli_core`)

| File |
|------|
| `GraphGdel_e_coli_core.sav` |
| `DNN_e_coli_core_Gene_AA.sav` |
| `DeepGdel_e_coli_core.sav` |
| `NMA_e_coli_core.sav` |

If a file is missing, the corresponding quick-run script may fall back to random initialization (not suitable for manuscript numbers).

HGPRGDel discs for all three GEMs: [`checkpoints/README.md`](../checkpoints/README.md).
